## MÓDULO 1: ¿Cómo implemento un Custom Hook en React 19 con TypeScript que gestione un flujo de telemetría por WebSockets con reconexión automática y backoff exponencial?

Para gestionar flujos continuos de telemetría en el laboratorio mediante [[React_19]], se debe desacoplar el ciclo de vida del socket del ciclo de renderizado del componente. Implementamos el custom hook `useWebSocketTelemetry` utilizando [[TypeScript]], con reconexión por [[Backoff_Exponencial]] con fluctuación aleatoria (*jitter*) para prevenir tormentas de reconexión (*thundering herd*) contra el broker.

```tsx
import { useState, useEffect, useRef, useCallback } from 'react';

interface TelemetryPacket {
  sensor_id: string;
  timestamp: number;
  value: number;
  unit: string;
}

interface UseWebSocketOptions {
  maxRetries?: number;
  baseDelayMs?: number;
  maxDelayMs?: number;
}

export const useWebSocketTelemetry = (
  url: string,
  options: UseWebSocketOptions = {}
) => {
  const { maxRetries = 10, baseDelayMs = 500, maxDelayMs = 15000 } = options;
  const [latestPacket, setLatestPacket] = useState<TelemetryPacket | null>(null);
  const [isConnected, setIsConnected] = useState<boolean>(false);
  const [error, setError] = useState<Error | null>(null);
  
  const socketRef = useRef<WebSocket | null>(null);
  const retryCountRef = useRef<number>(0);
  const reconnectTimerRef = useRef<number | null>(null);

  const connect = useCallback(() => {
    if (socketRef.current?.readyState === WebSocket.OPEN) return;

    try {
      const ws = new WebSocket(url);
      socketRef.current = ws;

      ws.onopen = () => {
        setIsConnected(true);
        setError(null);
        retryCountRef.current = 0;
      };

      ws.onmessage = (event: MessageEvent) => {
        try {
          const packet: TelemetryPacket = JSON.parse(event.data);
          setLatestPacket(packet);
        } catch (err) {
          setError(new Error('Fallo en la deserialización JSON de telemetría'));
        }
      };

      ws.onclose = () => {
        setIsConnected(false);
        if (retryCountRef.current < maxRetries) {
          const exponentialDelay = baseDelayMs * Math.pow(2, retryCountRef.current);
          const jitter = Math.random() * 200;
          const delay = Math.min(exponentialDelay + jitter, maxDelayMs);
          
          retryCountRef.current += 1;
          reconnectTimerRef.current = window.setTimeout(connect, delay);
        } else {
          setError(new Error('Límite de reintentos alcanzado en el socket de telemetría'));
        }
      };

      ws.onerror = () => {
        ws.close();
      };
    } catch (e) {
      setError(e instanceof Error ? e : new Error('Error en conexión WebSocket'));
    }
  }, [url, maxRetries, baseDelayMs, maxDelayMs]);

  useEffect(() => {
    connect();
    return () => {
      if (reconnectTimerRef.current) clearTimeout(reconnectTimerRef.current);
      if (socketRef.current) socketRef.current.close();
    };
  }, [connect]);

  return { latestPacket, isConnected, error };
};
```

El uso de `useRef` para el temporizador previene fugas de memoria y re-renderizados espurios.

## MÓDULO 2: ¿Cómo implementar un osciloscopio en tiempo real a 60 FPS con Canvas 2D en React evitando bloqueos en el hilo principal?

Para renderizar señales de alta frecuencia (ej. lecturas de ADC o acelerómetros) en [[React]], nunca se debe vincular cada muestra al estado `useState`. Se utiliza un búfer circular en memoria (`Float32Array`) y un ciclo de animación desacoplado mediante [[requestAnimationFrame]] sobre [[HTML5_Canvas]].

```tsx
import React, { useRef, useEffect } from 'react';

interface OscilloscopeProps {
  bufferRef: React.MutableRefObject<Float32Array>;
  width?: number;
  height?: number;
}

export const SignalOscilloscope: React.FC<OscilloscopeProps> = ({
  bufferRef,
  width = 800,
  height = 300
}) => {
  const canvasRef = useRef<HTMLCanvasElement | null>(null);

  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;
    const ctx = canvas.getContext('2d', { alpha: false });
    if (!ctx) return;

    let animationFrameId: number;

    const render = () => {
      const data = bufferRef.current;
      const bufferLength = data.length;

      ctx.fillStyle = '#0a0d14';
      ctx.fillRect(0, 0, width, height);

      ctx.strokeStyle = '#1e293b';
      ctx.lineWidth = 1;
      ctx.beginPath();
      for (let x = 0; x < width; x += 50) {
        ctx.moveTo(x, 0); ctx.lineTo(x, height);
      }
      for (let y = 0; y < height; y += 50) {
        ctx.moveTo(0, y); ctx.lineTo(width, y);
      }
      ctx.stroke();

      ctx.lineWidth = 2;
      ctx.strokeStyle = '#00f0ff';
      ctx.beginPath();

      const sliceWidth = width / bufferLength;
      let x = 0;

      for (let i = 0; i < bufferLength; i++) {
        const v = data[i];
        const y = (height / 2) - (v * (height / 2.2));
        if (i === 0) ctx.moveTo(x, y); else ctx.lineTo(x, y);
        x += sliceWidth;
      }

      ctx.stroke();
      animationFrameId = requestAnimationFrame(render);
    };

    animationFrameId = requestAnimationFrame(render);
    return () => cancelAnimationFrame(animationFrameId);
  }, [bufferRef, width, height]);

  return <canvas ref={canvasRef} width={width} height={height} style={{ borderRadius: '8px' }} />;
};
```

La opción `{ alpha: false }` en `getContext` desactiva la transparencia para permitir al rasterizador de la GPU operaciones directas de escritura rápida.

## MÓDULO 3: ¿Cómo implementar en Python 3.12 un pipeline concurrente con asyncio.TaskGroup y colas acotadas para evitar fugas de memoria por backpressure?

En sistemas de adquisición de datos en tiempo real, cuando la tasa de llegada de muestras supera la capacidad de procesamiento del host, las colas sin límite (`asyncio.Queue()`) saturan la memoria RAM hasta provocar [[OOM]]. En [[Python_3.12]] se emplea [[asyncio.TaskGroup]] junto a colas acotadas (`maxsize`), suspendiendo el productor cuando la cola se llena (*backpressure*).

```python
import asyncio
import time
from typing import NamedTuple

class SensorPacket(NamedTuple):
    device_id: int
    timestamp: float
    raw_voltage: float

async def hardware_producer(queue: asyncio.Queue[SensorPacket], device_id: int):
    for i in range(100):
        packet = SensorPacket(device_id=device_id, timestamp=time.time(), raw_voltage=3.3 * (i % 10) / 10.0)
        await queue.put(packet)  # Suspende si la cola alcanzó maxsize
        await asyncio.sleep(0.01)

async def processing_consumer(queue: asyncio.Queue[SensorPacket], worker_id: int):
    while True:
        packet = await queue.get()
        try:
            calibrated_val = packet.raw_voltage * 1.054 - 0.02
        finally:
            queue.task_done()

async def main():
    telemetry_queue: asyncio.Queue[SensorPacket] = asyncio.Queue(maxsize=50)
    async with asyncio.TaskGroup() as tg:
        p1 = tg.create_task(hardware_producer(telemetry_queue, device_id=1))
        p2 = tg.create_task(hardware_producer(telemetry_queue, device_id=2))
        consumers = [tg.create_task(processing_consumer(telemetry_queue, i)) for i in range(3)]
        await p1
        await p2
        await telemetry_queue.join()
        for c in consumers:
            c.cancel()

if __name__ == '__main__':
    asyncio.run(main())
```

`TaskGroup` provee manejo de errores simétrico: si una corrutina lanza una excepción, cancela automáticamente las demás tareas del grupo.

## MÓDULO 4: ¿Cómo implementar en Python un análisis espectral FFT en tiempo real con SciPy y NumPy para detectar resonancias mecánicas en motores paso a paso?

Para diagnosticar frecuencias de resonancia en motores paso a paso o efectores de impresión 3D, se muestrea un acelerómetro triaxial ([[ADXL345]]) y se aplica la [[Transformada_Rápida_de_Fourier]] (FFT) con una ventana de Hanning para minimizar la fuga espectral (*spectral leakage*).

```python
import numpy as np
from scipy.fft import rfft, rfftfreq
from scipy.signal.windows import hann

def compute_resonance_peaks(samples: np.ndarray, sampling_rate_hz: float, top_k: int = 3):
    """
    samples: Array 1D de aceleración en mm/s²
    sampling_rate_hz: Frecuencia de muestreo (ej. 3200 Hz)
    Retorna las frecuencias dominantes en Hz y sus amplitudes relativas.
    """
    n = len(samples)
    # 1. Eliminación del componente de continua (offset de gravedad)
    detrended = samples - np.mean(samples)
    
    # 2. Aplicación de ventana de Hanning
    window = hann(n)
    windowed_signal = detrended * window
    
    # 3. FFT para señales reales (rfft optimizada)
    fft_values = rfft(windowed_signal)
    frequencies = rfftfreq(n, d=1.0 / sampling_rate_hz)
    
    # 4. Cálculo de densidad espectral de potencia
    amplitudes = np.abs(fft_values) * (2.0 / np.sum(window))
    
    # 5. Detección de picos máximos ordenados
    peak_indices = np.argsort(amplitudes)[::-1][:top_k]
    
    return [(float(frequencies[idx]), float(amplitudes[idx])) for idx in peak_indices]
```

Esta transformada permite obtener los valores exactos para sintonizar los filtros de compensación de vibración [[Input_Shaper]] (`mzv`, `ei`, `2hump_ei`).

## MÓDULO 5: ¿Cómo optimizar el uso de memoria en clases de Python mediante __slots__ y tipos inmutables para procesar millones de registros de telemetría?

En [[Python]], cada instancia convencional de una clase almacena sus atributos en un diccionario dinámico `__dict__`. Esto introduce una sobrecarga de memoria de aproximadamente 152 bytes por objeto. Para procesar millones de muestras de telemetría sin desbordar la memoria RAM, se define `__slots__` o se emplean `@dataclass(slots=True)`:

```python
from dataclasses import dataclass
import sys

# Clase optimizada con slots a nivel de CPython
@dataclass(slots=True, frozen=True)
class TelemetryRecord:
    timestamp_ns: int
    channel_id: int
    voltage: float
    current: float

# Comparativa de memoria:
class RegularRecord:
    def __init__(self, t: int, ch: int, v: float, i: float):
        self.timestamp_ns = t
        self.channel_id = ch
        self.voltage = v
        self.current = i

rec_regular = RegularRecord(1710000000, 1, 3.3, 0.45)
rec_slotted = TelemetryRecord(1710000000, 1, 3.3, 0.45)

# Regular: objeto (~48 bytes) + __dict__ (~112 bytes) = ~160 bytes
# Slotted: estructura C fija = ~56 bytes (ahorro de más del 65% de RAM)
```

Al fijar los atributos con `slots`, CPython genera punteros directos en la estructura interna de C en lugar de tablas hash dinámicas, acelerando además el acceso a atributos en un 20%.
