Entrega de Modelo Cuantizado (sentinel-stem.Q4_K_M.gguf)

Listo para Producción

El modelo final en formato GGUF está podado y optimizado para ejecutarse en procesadores modestos de escuelas mediante llama.cpp, Ollama, LM Studio o servidores educativos locales sin depender de GPU.

Opción A: Servidor HTTP Local Ultrarrápido (LAN)

Descarga directa desde cualquier laptop o Raspberry Pi en la red del aula:

python -m http.server 8080 --directory export\output_gguf

En la máquina del aula: curl -O http://[IP_DE_ESTA_PC]:8080/sentinel-stem.Q4_K_M.gguf

Opción B: Transferencia Segura por Red (SSH / SCP)

Transfiere directamente al servidor Linux de la escuela:

scp .\export\output_gguf\sentinel-stem.Q4_K_M.gguf usuario@ip_servidor_escuela:/opt/models/
Opción C: Copia a Pendrive / Disco USB

Ruta absoluta lista para copiar en Windows Explorer o PowerShell:

Copy-Item ".\export\output_gguf\sentinel-stem.Q4_K_M.gguf" -Destination "E:\" -Verbose
